# 126 种版式 · 四大家族详细参数

## TYP 家族（TYP-001 ~ TYP-036）
### 单页 · 大字错落断行 + 扁平星芒贴纸

**视觉特征**：
- 将月份或情绪大词拆分为三行紧凑堆叠的圆润粗体无衬线小写字母（如 `nov` / `em` / `ber` 或 `sun` / `day` / `mood`）
- 整体做 `-6° ~ -8°` 俏皮微倾斜
- 落位在人物腰腹/裙摆区的视觉重心处，**绝对避开五官**

**色彩联动**：
- 大字颜色自动吸取人物穿搭主色调（鹅黄长裙→奶油黄 `#FFF3B0`，深色学院风→暖米白 `#FFF8E7`）
- 周围穿插 3~4 颗撞色复古扁平五角星/八角星芒贴纸
- 贴纸色：珊瑚粉 `#F26B8A` + 奶油黄 `#FCE38A`，带轻微前后遮挡穿插感

## JNL 家族（JNL-037 ~ JNL-072）
### 组图 · 括号画中画照片日记

**视觉特征**：
- 以 1 张全身/半身主图作为满幅背景
- 画面中纵向排布 3 行极简无衬线白字短句：
  - 第一行：`what I (  [内嵌横版缩略图 01]  )`
  - 第二行：`did (  [内嵌横版缩略图 02]  )`
  - 第三行：`in nov (  [内嵌横版缩略图 03]  )`

**内嵌图逻辑**：
- 多张同组照片：括号内依次嵌入同组其余 3 张照片
- 仅 1 张照片：自动对原图做 3 处高审美局部特写切片（面部神态/穿搭局部/街景橱窗）填入

## GAL 家族（GAL-073 ~ GAL-102）
### 单页/组图 · 高克重画廊留白与无字切片拼图

**视觉特征**：
- 保留最外圈 Ins 顶底栏
- 中间画布采用 `#F4F2EC` 暖白艺术纸衬底
- 单张居中留白或 4 宫格非对称多焦段纯净拼图
- 0 文字、0 贴纸干扰

---

## MAG 家族（MAG-103 ~ MAG-126）
### 杂志感留白衬线刊头

**视觉特征**：
- 外圈 Ins 顶底栏 + 极简无遮挡大画幅
- 底部或边角一行克制的杂志衬线斜体注脚
